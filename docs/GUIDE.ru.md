## 1. Установите зависимости

AudioFX получает звук через cava. Для свечения также нужен python3 с numpy и Pillow.

```sh
# Arch
sudo pacman -S cava python-numpy python-pillow
# Fedora
sudo dnf install cava python3-numpy python3-pillow
```

## 2. Установите и включите плагин

Из реестра плагинов:

```sh
dms plugins install audioFx
```

Или клонируйте репозиторий в папку плагинов DMS:

```sh
git clone https://github.com/satoshoe-dev/dms-audiofx ~/.config/DankMaterialShell/plugins/AudioFx
```

Откройте Настройки → Дополнения и включите AudioFX.

![Список плагинов с AudioFX](images/01-plugin-list.png)

## 3. Только niri: закрепите на месте

В niri фоновые поверхности перемещаются вместе с рабочими столами, если они не находятся в backdrop. Добавьте эти правила в `~/.config/niri/config.kdl`:

```kdl
layer-rule {
    match namespace="^audiofx$"
    place-within-backdrop true
}
layer-rule {
    match namespace="^audiofx-glow$"
    place-within-backdrop true
}
```

Другим композиторам это не нужно.

## 4. Визуализатор

Включите музыку. Визуализатор появится вдоль нижнего края.

![Визуализатор у нижнего края](images/02-visualizer.png)

Чтобы изменить его, разверните AudioFX в списке плагинов. «Стиль» переключает волны, полосы, блоки и точки. «Край», «Глубина» и «Боковой отступ» задают положение. «Цвет» и «Непрозрачность» задают внешний вид.

![Настройки визуализатора](images/03-visualizer-settings.png)

Если полосы мерцают в тихих местах, увеличьте «Плавность». Если они почти не двигаются, увеличьте «Чувствительность».

## 5. Включение и выключение из центра управления

Откройте центр управления, перейдите в режим редактирования, нажмите «Добавить виджет» и выберите AudioFX. Один щелчок по плитке включает или выключает визуализатор.

![Плитка AudioFX в центре управления](images/04-tile.png)

## 6. Свечение

Прокрутите до «Свечение на обоях» и включите «Включить свечение». AudioFX ищет светящиеся места на ваших обоях. В первый раз это занимает около секунды, потом результат берётся из кэша.

![Настройки свечения](images/05-glow-settings.png)

Свечение лучше всего работает с обоями, на которых есть небольшие яркие источники света: лампы, неон, угли, огни города. На обоях без таких мест ничего не загорается.

Выберите, как реагируют места, в разделе «Как пульсируют места»:

- Одновременно
- По высоте тона
- Поток
- Мерцание
- Спектр по ширине

![Светящиеся места на обоях](images/06-glow.png)

Если загорается слишком много или слишком мало, передвиньте «Порог распознавания». «Яркость свечения» и «Ореол» меняют яркость.

## 7. Диск плеера

Откройте Настройки → Виджеты рабочего стола → Добавить виджет рабочего стола и выберите AudioFX. Перетащите диск в нужное место и измените его размер.

![Диск плеера на рабочем столе](images/07-disc.png)

При наведении на диск появляются кнопки предыдущего трека, воспроизведения и следующего трека. В разделе «Диск плеера» настроек AudioFX выберите визуализатор вокруг обложки: волну, полосы по кругу или светящееся кольцо.

## 8. Команды (необязательно)

```sh
dms ipc call audiofx glow toggle
dms ipc call audiofx mode flow
dms ipc call audiofx set glowStrength 150
```
