# AudioFX

Плагин для [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell) с тремя аудиоэффектами: визуализатор вдоль края экрана, свечение, от которого яркие места обоев пульсируют под музыку, и круглый диск плеера для рабочего стола.

![AudioFX](assets/screenshot.png)

Пошагово с картинками: [руководство по установке и настройке](docs/GUIDE.ru.md).

## Визуализатор

Визуализатор располагается вдоль одного края экрана и не заходит на рамку и панель DMS. Есть восемь стилей: заполненная волна, волна линией, зеркальная волна, полосы, зеркальные полосы, свисающие полосы, блоки и точки. Настраиваются цвет, непрозрачность, глубина, число полос частот, промежуток и частота кадров.

По умолчанию cava работает, только пока играет MPRIS-плеер, и завершается, когда воспроизведение останавливается. Если выключить «Только во время воспроизведения», cava работает постоянно и показывает также звук программ без MPRIS. Плитка в центре управления включает и выключает визуализатор.

## Свечение

Плагин ищет светящиеся места на текущих обоях: насыщенные яркие пиксели самого частого оттенка, которые выделяются на фоне окружения. Хорошо подходят лампы, угли, неон или лава. Большие равномерно освещённые области, например небо, не учитываются. Анализ выполняется один раз для каждых обоев и кэшируется.

Затем места загораются под музыку. Есть пять режимов:

- Одновременно: все места следуют за басом и громкостью.
- По высоте тона: большие места следуют за басом, средние за средними частотами, маленькие за высокими.
- Поток: каждый удар баса посылает световую волну вдоль мест, начиная от края изображения.
- Мерцание: каждое место мерцает в своём ритме.
- Спектр по ширине: низкие ноты слева, высокие справа.

Без воспроизведения свечение может быть выключено, тихо тлеть или медленно дышать. Цвет берётся из изображения или из акцента DMS.

## Диск плеера

Виджет рабочего стола с круглой обложкой текущего трека. Он вращается во время воспроизведения, показывает прогресс трека кольцом, а при наведении показывает «назад», «воспроизведение» и «вперёд». Вокруг обложки есть визуализатор: волна как на панели управления DMS, полосы по кругу или светящееся кольцо.

Если Pear Desktop (YouTube Music) запущен с включённым API-сервером, диск загружает обложку в 1200 px. Через MPRIS плееры на основе Chromium отдают только 120 px.

## Требования

- DankMaterialShell 1.6.1 или новее
- cava
- Для свечения: python3 с numpy и Pillow

Я пользуюсь им в niri. Визуализатор и свечение используют собственные layer surfaces на слое background. В niri поверхности этого слоя перемещаются вместе с рабочими пространствами, если они не помещены в backdrop. Добавьте эти правила в конфигурацию niri, чтобы оба оставались на месте:

```kdl
layer-rule {
    match namespace="^audiofx$"
    place-within-backdrop true
}
layer-rule {
    match namespace="^audiofx-glow$"
    place-within-backdrop true
}
```

Диск плеера является обычным виджетом рабочего стола DMS и ведёт себя так же, как другие виджеты в вашем композиторе.

## Установка

Из реестра плагинов:

```sh
dms plugins install audioFx
dms ipc call plugins enable audioFx
```

Плагин также есть в каталоге DMS: Настройки → Дополнения. Установка из репозитория:

```sh
git clone https://github.com/satoshoe-dev/dms-audiofx ~/.config/DankMaterialShell/plugins/AudioFx
dms ipc call plugins enable audioFx
```

Диск плеера добавляется в разделе Настройки → Виджеты рабочего стола → Добавить виджет рабочего стола → AudioFX.

## IPC

```sh
dms ipc call audiofx glow on|off|toggle
dms ipc call audiofx mode sync|bands|flow|sparkle|spectrum
dms ipc call audiofx set <key> <value>
dms ipc call audiofx get <key>
```

`set` и `get` используют ключи из настроек плагина, например `glowStrength` или `discForm`.

## Производительность

Свечение покрывает весь экран, поэтому композитор перерисовывает его в каждом кадре, пока играет музыка. Частота кадров свечения по умолчанию равна 30, её можно снизить. За пределами светящихся мест шейдер сразу возвращает результат.

## Переводы

Страница настроек доступна на немецком, испанском, французском, итальянском, португальском, русском, японском и упрощённом китайском и следует языку, выбранному в DMS. Если перевод звучит неправильно, pull request приветствуется.
